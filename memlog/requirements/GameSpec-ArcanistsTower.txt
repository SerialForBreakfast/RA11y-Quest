Curriculum note
===============
This game teaches **navigation-class** VoiceOver rotor settings (Headings, Containers,
Links). It does **not** teach **Rotor Actions** (ADR-0006). It does **not** include
**Adjustable** in v1.

Game ID
=======
arcanists-tower

Canonical name (player-facing)
==============================
The Threefold Seal — do **not** use legacy “Arcanist’s Tower” / wizard ascent copy in UI or VO strings.

Working hub title key (implementation)
======================================
game.arcanistsTower.title

One-sentence lesson
===================
Twist the rotor so your next and previous flicks jump the kind of thing you need —
chapter titles, whole storage regions, or links — then open what the clue names.

Prerequisites
=============
Catalog prerequisite: player must have completed **The Banishment**
(`the-banishment`) before this game unlocks.

Stage structure (DesignProcess)
================================
Three stages exist at product level; **v1 implementation may ship Practice only** first,
then Trial, then Lights Off in follow-on milestones.

Stage 1 — Practice: Guided sequence (three beats)
--------------------------------
Timer: none (optional soft stall timer TBD).
Rank: none.

Sequence:
1. Prologue — rotor gesture + fiction frame; one Continue control.
2. Beat A — Headings (title plates + short body).
3. Beat B — Containers (three labeled storage niches).
4. Beat C — Links (margin bound marks; 3–4 links, optional one trap).

Hints: Practice may **name** Headings, Containers, Links **once per beat** in copy.
Trial naming rules do **not** apply here.

Success: all three beats completed.

Failure: none in Practice; wrong activations use wrong-action policy below.

Stage 2 — Trial: Scrambled archive (optional v1 or v1.1)
----------------------------------------------------
Timer: initial tuning **60 seconds** (adjust after device playtests).

Rank: Legendary / Skilled / Novice / Defeated per RankThresholds.arcanistsTower.

Sequence:
- Three rounds, one round per discipline, **random order**, each discipline exactly once.
- Cues are **environmental only** — do **not** name rotor settings.

Hints: none (cue lines and room identity only).

Success: all rounds complete before timeout.

Failure: timeout before completion.

Stage 3 — Lights Off
--------------------
Deferred for v1 **or** gated post-first-clear. When enabled: same semantic tree as
Trial; darkened visuals; audio/haptics identity per RotorNavigationQuestBrainstorming
§11.5. Timer initial **75 seconds** (tune after playtest).

Discipline A — Headings (title hall)
======================================
Rotor setting: Headings.

Challenge: activate the **named title plate** among 4–6 headings; body text remains
accessible and non-heading.

Practice: literal target name in objective strip; wrong heading → instructional tone
allowed briefly (see QuestConcept).

Trial: riddle / cue only; wrong heading → +1 mistake, outcome line only.

Required semantics: real heading traits on titles; mistakes detected by **which**
heading activated.

Discipline B — Containers (storage row)
=======================================
Rotor setting: Containers.

Challenge: open the **named storage niche** among **three** labeled container regions.

Clue: name + one **non-color** cue (material word, emblem description, or audio).

Wrong niche: outcome line (“That niche was empty.” / similar); +1 mistake in Trial.

Required semantics: each niche is a real accessibility **container** (or combined
region) with a distinct **accessibilityLabel**; inner control is clearly the “open”
action for detection.

Discipline C — Links (bound marks)
==================================
Rotor setting: Links.

Challenge: activate the **named bound mark** among 3–4 links; at most one trap link.

Wrong link: trap outcome line; +1 mistake in Trial.

Required semantics: targets use link semantics; prose remains readable.

Wrong-action model (all stages)
===============================
- Never say “wrong rotor” or name the wrong rotor setting in Trial.
- Detect **wrong activation** by element identity; never query rotor UI state.
- Cooldown between counted mistakes: **800–1200 ms** (tune in implementation).
- Stay on the same beat/round after a mistake unless Trial design specifies otherwise.

Rank thresholds (RankThresholds.arcanistsTower)
===============================================
Initial preset (adjust after playtest):
- timeoutSeconds: 60
- perfect: time ≤ 25 s, mistakes ≤ 0
- good:    time ≤ 45 s, mistakes ≤ 1
- ok:      time ≤ 60 s, mistakes ≤ 3
- else Failed

VoiceOver announcement schedule
===============================
- Prologue screen load: layoutChanged to Continue when ready.
- Each beat entry: announce objective + seal progress (e.g. “Seal one of three”).
- Wrong action: immediate announcement; rate-limited.
- Trial: room cue at round start; timer milestones 50% / 25% / 10 s (if enabled).

Haptic schedule (initial)
=======================
- Practice wrong: light warning; success: light success.
- Trial wrong: medium warning; round complete: soft tick; all clear: success pulse.

Audio cue schedule (initial)
============================
- Headings: parchment shuffle (short).
- Containers: stone grind (short).
- Links: glass chime (short).
- Duck audio under VoiceOver when both would compete (same policy as other quests).

Testing

reaches bound marks; Practice completable without sight.
