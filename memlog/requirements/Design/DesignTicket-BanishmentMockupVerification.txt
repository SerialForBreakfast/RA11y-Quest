Banishment Product Criteria
----------------------------

- PASS - Ward state establishes practice framing: instruction visible, creature present.
- PASS - Tower states are visually distinct from ward (darker backdrop, timed feel).
- PASS - Lights Off (dark) state is readable as a "lights out" encounter — creature
  silhouette against near-black, minimal visual cues.
- PASS - Banished state communicates escape success without implying a button was pressed.
- PASS - No state exposes a tappable "escape" affordance; gesture must be performed.

QuestPaint Consistency
----------------------

- PASS - Warm torchlit stone mood in ward; darker tower and Lights Off states darken
  progressively, consistent with RA11y QuestPaint direction.
- PASS - Creature silhouettes are distinct by shape (goblin, skeleton, orc, troll, dragon).
- PASS - Banished success state uses creature-agnostic dissolve/flare, not a
  species-specific VFX — matches BanishmentAssetPipeline §"Success feedback must be
  creature-agnostic."
- NOTE - Mockups are more ornate than final SwiftUI implementation. App keeps current
  QuestPaint text roles and token spacing; images serve as visual direction only.

1. Opaque illustrated background (banishment_ward_bg / banishment_tower_bg).
2. Code-drawn dark trap veil (black overlay ~70-80% opacity).
