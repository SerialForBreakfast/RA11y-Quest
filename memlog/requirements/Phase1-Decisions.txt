RA11y - Accessibility Training Gamification
Phase 1 Decisions (Snapshot)

Date: 2026-02-20

Scope
-----
- Audience: General users (also useful for designers/dev/QA).
- MVP Platform: iOS.
- OS Targets: iOS 18+ (current + previous line under year-based naming).
- Future platforms follow the same policy: macOS 15+, tvOS 18+.

Navigation
----------
- Sandbox-first hub.
- First-run optional “VoiceOver Basics” sequence.

VoiceOver
---------
- MVP Skills: Focus navigation, Activate (double-tap), Scroll (3-finger).
- Games are VoiceOver-on only (no preview mode).
- VO off: gate with interstitial + Settings open (best-effort deep-link + fallback) + in-app steps.

Scoring + Storage
-----------------
- Hub displays rank only (display names: Legendary / Skilled / Novice / Defeated).
- Internal rank enum: Perfect / Good / Ok / Failed.
- Scoring model supports optional per-game metrics.
- Persist best result per game.
- StorageComponent abstraction; UserDefaults first; SwiftData later.

Privacy + Telemetry
-------------------
- Offline-first, no tracking for MVP.
- Future: modular opt-in GameKit possible.

Localization
------------
- All user-visible strings are localized from day 1 using String Catalogs (`Localizable.xcstrings`).
- Avoid hard-coded strings; always use localized keys even for English defaults.
