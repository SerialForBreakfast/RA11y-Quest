Notes
---
- RA11y-iOS uses PBXFileSystemSynchronizedRootGroup — new files in subdirectories are
  auto-included in the target without editing project.pbxproj.
- RA11yCore is linked to the RA11y-iOS app target as a local SPM package.
- SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor is set at the project level — all app code
  is implicitly @MainActor unless annotated otherwise.
- String Catalog (Localizable.xcstrings) is set up with English strings; localization
  support requires only new catalog entries (no code changes) in future.
