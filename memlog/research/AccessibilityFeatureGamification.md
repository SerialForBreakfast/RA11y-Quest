# Accessibility Feature Gamification

This document proposes 3 standalone game ideas for each accessibility feature. Each game is focused on teaching exactly 1 feature.

## Move focus to element — single tap

1. Firefly Finder: The player explores a dark scene by tapping around the screen until the target object is focused. This teaches touch exploration and reinforces that a single tap moves VoiceOver focus without activating.
2. Potion Bench: A table of ingredients is spread across the screen, and the player must find the requested ingredient by tapping different areas. This teaches spatial discovery and deliberate focus placement.
3. Constellation Touch: The player searches a star map for a named star using touch exploration. This teaches how to directly move focus to a specific on-screen element.

## Navigate element by element — swipe right / left

1. Hallway Patrol: The player moves through a line of objects using only left and right swipes until they find the target. This teaches predictable sequential navigation.
2. Relic Shelf: A row of relics must be searched item by item with swipe gestures. This teaches linear traversal without relying on direct touch.
3. Train Car Search: Each swipe moves focus to the next passenger or object in a train car. This teaches how to move steadily through a structured interface.

## Activate focused element — double-tap

1. Rune Switch: The player focuses a rune and must double-tap to activate it. This teaches the separation between selecting an element and performing its action.
2. Treasure Latch: A chest has several focusable parts, but only the latch opens with a double-tap. This teaches intentional activation after confirming focus.
3. Signal Beacon: The player focuses a control and double-taps to send a signal. This builds muscle memory for the VoiceOver activate gesture.

## Scroll the page — three-finger swipe up / down

1. Crystal Shaft: The player explores a tall vertical mine by scrolling up and down to reach hidden content. This teaches page movement beyond the visible screen.
2. Tower Records: A long ledger spans multiple pages, and the player must scroll to find a named entry. This teaches the difference between element navigation and page scrolling.
3. Garden Rows: The player moves through a long garden using three-finger scrolling to find a specific plant. This teaches how to navigate extended layouts.

## Dismiss / go back — two-finger scrub

1. Escape the Modal: The player opens overlays and must leave them using the scrub gesture. This teaches how to get out of temporary views without hunting for a button.
2. Mist Portal: The player enters a wrong room and uses the scrub gesture to back out. This teaches the VoiceOver escape gesture as a fast recovery tool.
3. Spell Reversal: The player opens the wrong page in a spellbook and must return with a scrub. This reinforces gesture-based back navigation.

## Custom actions on an element — swipe up / down on focused element

1. Mail Falcon: The player focuses a message and cycles through actions like archive or flag using swipe up and down. This teaches that useful commands can exist directly on an item.
2. Inventory Belt: A focused item offers actions like equip, inspect, or drop. This teaches contextual actions without opening a detail screen.
3. Town Noticeboard: A posted item can be pinned, shared, or marked complete through custom actions. This teaches how to operate on the current element efficiently.

## Pause and resume speech — two-finger tap

1. Bard’s Tale: A narrator reads a clue aloud and the player pauses speech to think before resuming. This teaches control over spoken output.
2. Oracle Chamber: The player listens for key instructions, pauses speech when needed, then resumes after acting. This teaches interruption without losing context.
3. Signal Monitor: A transmission is being read while hazards appear, so the player pauses speech, handles the issue, then resumes. This teaches speech control during multitasking.

## Navigate by heading — Rotor → Headings → swipe up / down

1. Library Atlas: The player moves between major sections of a long document using heading navigation. This teaches fast structural movement through content.
2. Fortress Directory: The player jumps between castle sections labeled as headings to find a target room. This teaches how headings speed up navigation.
3. Quest Journal: The player locates the correct quest section by moving heading to heading instead of swiping through every element. This teaches efficient content scanning.

## Read all from here — two-finger swipe down

1. Campfire Briefing: The player starts continuous reading from the correct point and listens for an important detail. This teaches passive listening mode.
2. Museum Audio Guide: The player begins reading from a plaque and answers a question after listening. This teaches how to consume long content without manual navigation.
3. Royal Proclamation: The player starts reading from the middle of a decree and listens through the rest. This teaches choosing the right starting point for continuous reading.

## Jump to first / last element — four-finger tap top / bottom

1. Elevator Recall: The player is dropped in the middle of a long screen and must jump instantly to the beginning or end. This teaches rapid orientation.
2. Scroll Tome: The player compares the first and last sections of a long scroll using jump shortcuts. This teaches fast movement between extremes.
3. Ship Manifest: The player repeatedly checks the first and last cargo entries using top and bottom jumps. This teaches efficient screen boundary navigation.

## Containers and groups — entering / exiting grouped content

1. Market Stalls: The player moves among grouped stalls, then enters the correct one to inspect items inside. This teaches the distinction between group-level and item-level navigation.
2. Armory Racks: Weapons are organized into grouped racks and the player must enter the right group before searching inside it. This teaches grouped structure.
3. Puzzle Cabinet: The player navigates cabinet sections, then enters a drawer group to find the target piece. This teaches why some interfaces skip over chunks until entered.

## Magic Tap — two-finger double-tap

1. Tavern Jukebox: The player uses Magic Tap to play and pause music. This teaches the context-aware primary action gesture.
2. Messenger Hawk: An incoming communication is answered or ended with Magic Tap. This teaches the shortcut for the most obvious current action.
3. Chronicle Playback: A narrated memory scene starts and stops with Magic Tap. This teaches quick context-sensitive media control.

## Navigate by link — Rotor → Links

1. Web of Sigils: The player jumps only between links on a page to find the needed reference. This teaches filtering navigation to actionable text.
2. Scholar’s Notes: The player moves among citations and references using link navigation. This teaches efficient web-style content traversal.
3. City Guide: The player skips plain text and jumps directly through tappable destinations. This teaches how rotor link mode isolates interactive references.

## Navigate by form control — Rotor → Form Controls

1. Passport Office: The player moves only between fields, switches, and buttons in a long form. This teaches efficient form completion.
2. Alchemist Registration: A guild signup page contains many labels and descriptions, but the player uses Form Controls to reach only interactive elements. This teaches filtering out non-controls.
3. Device Setup Bay: The player navigates a settings screen by moving only among toggles and selectors. This teaches direct movement between input controls.

## Navigate by landmark — Rotor → Landmarks

1. Castle Map: The player jumps between major structural regions like navigation, content, and footer. This teaches screen structure awareness.
2. Harbor Terminal: The player moves between major zones of a busy layout using landmarks. This teaches skipping repeated chrome and jumping to main content.
3. News Hall: The player navigates a rich page by moving between distinct regions instead of every single element. This teaches large-scale page movement.

## Long press via VoiceOver — double-tap and hold

1. Forge Press: The player focuses a control and must double-tap and hold until the machine engages. This teaches the VoiceOver version of long press.
2. Seed Planter: The player holds on a plot to place a seed successfully. This teaches timing and intent for hold-based actions.
3. Safe Dial: The player starts unlocking a safe by activating and holding the focused control. This teaches the difference between a quick activate and a sustained action.

## Screen Curtain — two-finger triple-tap

1. Blind Trial: The player turns the screen dark and completes a simple task using audio alone. This teaches confidence in nonvisual operation.
2. Night Archive: A stealth challenge requires using Screen Curtain while continuing navigation. This teaches the feature as intentional and useful, not just obscure.
3. Trust Fall: The player repeats a previously learned task with the screen hidden. This teaches reliance on VoiceOver instead of visuals.

## Text input with VoiceOver — typing modes

1. Wizard Name Entry: The player enters a character name while learning how VoiceOver typing differs from standard visual typing. This teaches the changed input model.
2. Cipher Console: The player types a short code into a machine using VoiceOver text entry. This teaches focused text input under assistive interaction.
3. Message Desk: The player types and sends a short note while learning VoiceOver typing flow. This teaches practical text entry in a common scenario.

## Read character by character — Rotor → Characters → swipe up / down

1. Rune Proofreader: The player examines a password one character at a time to find an error. This teaches fine-grained text review.
2. Serial Plate: The player verifies a code character by character on a machine label. This teaches precision reading for identifiers.
3. Spell Comparator: Two similar words differ by one letter, and the player uses character navigation to find it. This teaches careful proofreading.

## Navigate by word — Rotor → Words

1. Clue Scanner: The player advances word by word through a sentence until the important keyword is found. This teaches a practical reading granularity.
2. Contract Review: The player inspects a line of text word by word to locate a key term. This teaches efficient review without going character by character.
3. Whisper Transcript: The player scans a transcript word by word for a hidden instruction. This teaches selective text navigation.

## Split tap — hold one finger, tap with another

1. Crystal Trigger: The player keeps one finger on a control and activates it with another. This teaches split tap as an alternative to double-tap.
2. Trap Door: The target is easier to keep under one finger than to refocus after lifting. This teaches why split tap can be more reliable.
3. Precision Console: Small controls are easiest to activate by holding one finger in place and tapping with another. This teaches the practical value of split tap.

## Adjust a slider or picker — swipe up / down on focused control

1. Cauldron Heat: The player adjusts a heat slider to hit the exact target value. This teaches how adjustable controls work.
2. Clock Tower: The player changes a picker to the correct time using swipe up and down. This teaches incremental value adjustment.
3. Signal Tuner: The player tunes a dial to the right frequency through adjustable control gestures. This teaches listening to value changes and stopping at the correct point.

## Speaking rate — Rotor → Speech Rate

1. Pace Trainer: The player changes VoiceOver speed to match the challenge level. This teaches that speaking rate is adjustable and useful.
2. Courier Rush: A time-sensitive round rewards faster speech, while a careful round rewards slower speech. This teaches adapting speech rate to context.
3. Listening Lab: The player compares clue playback at different rates and chooses the most comfortable setting. This teaches personalization.

## Verbosity control — Settings → Accessibility → VoiceOver → Verbosity

1. Signal Noise: The player completes the same task once with high verbosity and once with reduced verbosity. This teaches how extra spoken details affect speed and load.
2. Apprentice to Expert: Early rounds include more spoken guidance, while later rounds reduce it. This teaches why experienced users may prefer less verbosity.
3. Command Deck: The player tries different verbosity profiles on a complex screen and chooses the one that feels most efficient. This teaches tradeoffs in spoken detail.

## Hints on / off — VoiceOver hints setting

1. Training Wheels: The player completes a task with hints on, then repeats it with hints off. This teaches the role of hints in early learning.
2. Veteran Mode: Higher-score rounds disable hints for faster play. This teaches hints as optional support rather than required speech.
3. Echo Filter: The player toggles hints and hears how repeated instruction changes the experience. This teaches comfort and efficiency tradeoffs.

## Typing feedback — character echo vs. word echo

1. Scribe Workshop: The player types a short phrase with different feedback modes and compares how each sounds. This teaches the meaning of typing feedback settings.
2. Whisper Keyboard: One task favors less spoken interruption, while another favors more confirmation. This teaches why users choose different feedback styles.
3. Dictation Desk: The player changes typing feedback during a note-writing task and hears the difference immediately. This teaches the comfort and confidence implications of each setting.

## Custom pronunciation — VoiceOver pronunciation settings

1. Name of Power: A fantasy name is spoken incorrectly until the player adds a custom pronunciation. This teaches how pronunciation settings improve clarity.
2. Guild Registry: Unusual names and places are hard to understand until custom pronunciations are configured. This teaches maintenance of a personal vocabulary.
3. Personal Dictionary: The player gradually builds a pronunciation list for important names used in the game world. This teaches long-term personalization of spoken output.
